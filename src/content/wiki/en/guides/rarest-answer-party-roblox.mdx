Rarest Answer Party is a Roblox experience where the public pitch is simple: a rarer answer scores more points, and you win by outscoring the other people in the match. It is not the browser game on this site. The names are close enough that people search them together. This page separates them, and it only states what Roblox's own page and games API showed on 14 November 2026.

Play the browser game from the [homepage](/), and read its [rules](/guides/how-to-play-rarest-answer/) if you want tiers and Spotlight. Stay here if you want the Roblox party.

## What is Rarest Answer Party on Roblox?

The canonical page is [Rarest Answer Party on Roblox](https://www.roblox.com/games/70967715806705/Rarest-Answer-Party). On 14 November 2026 the HTML title was "Rarest Answer Party! | Play on Roblox." The games API returned a longer display name that added an update prefix and a shrimp emoji. Those decorations change when the creator retitles the experience. The place id does not: `70967715806705`. The universe id on that read was `10772648808`.

The creator field was the Roblox group Torrey Pines, group id 421623341, with a verified badge. Creator type was Group. The licensed flag was false. Nothing on the payload ties this place to this website, to Krillion, or to any other rarest-answer site. "Official" here means the Roblox page for this place id.

The genre fields were Party and Casual, and Quiz. Price was null, so that read showed no entry fee. Copying was not allowed.

## What does the official description actually say?

The description text returned by the games API was short. Paraphrased without the emoji, it says:

- The rarer your answer, the more points you get.
- Outscore everyone to win.
- Private servers are described as free, and as a way to play with friends.
- Difficulty servers are named Easy, Medium, Hard, and Random.
- Private servers "allow you to customize the match."
- You can collect mics and chairs.
- The description ends by asking "Do you have Ball Knowledge?"

That is the entire rule set the creator published in that field. It does not include a points table, a timer length, a list of prompts, or a definition of the four difficulties. It does not say what a mic or a chair does, whether they are cosmetic, or whether they change the score. It does not explain the Ball Knowledge question. This guide will not invent those answers. If you need them, they have to come from inside the experience or from a later official description, not from a fan wiki's guess.

The description we read also contained no redeem code. A code list on another domain is not this Roblox page.

## How is a party match different from the daily browser game?

Both games pay more for a less obvious correct answer. The similarity stops at that idea.

This site's daily is seven prompts, the same seven for everyone, resetting at local midnight, scored on six named tiers from Common at 5 points to Legendary at 100, with one Spotlight double per round. Stats stay in your browser. There is an [unlimited mode](/unlimited/) and a per-category mode. None of that is written on the Roblox description, so do not assume the party uses it.

The Roblox description is a shared room: outscore the people in the match. `maxPlayers` was 6, so the comparison is a handful of players, not a global daily population. A name can be rare in that room simply because the other five did not type it. In the browser game, rarity is a rank on a prepared list. That is a different contest. The prepared-list habit is [finding rare answers](/guides/how-to-find-rare-answers/). In a six-person room you still need a name that fits, and that the others are less likely to share. There is no published global tier to look up.

Until the description says what Easy, Medium, and Hard change, those servers are not a strategy this page can write down.

## What should you do with a prompt inside the party?

The description says rarer answers score more, and it says you have to outscore the room. It does not publish the room's answer history. So the usable technique is the same one this site teaches, stopped one step earlier: skip the first famous name, pick a more specific name that still fits, and submit something you can defend before the timer you cannot see documented here runs out. The [strategy guide](/guides/rarest-answer-strategy/) is written for our tiers and our Spotlight. Borrow the "two names, sentence test" part. Do not borrow the 5-to-100 point table, because Rarest Answer Party has not published that table.

If the match is with friends on a private server, the description says you can customize the match. It does not say which knobs exist. Custom rules in a friend server are whatever that server enabled, not the daily rules on this website.

Check the Roblox page again when you play. The API `updated` time was already 14 November 2026, the same day as this writing, so the creator was shipping changes while the numbers above were copied. A guide that freezes a player count is a source note. It is not a live scoreboard.
